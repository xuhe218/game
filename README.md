# 双人召唤战线

纯 HTML + CSS + JavaScript 的电脑端双人同屏游戏可试玩版。无需后端、无需 npm、无需打包器。

## 运行方式

最简单方式：

1. 双击 `start_game.bat`
2. 浏览器会打开 `http://127.0.0.1:4177/`
3. 关闭命令行窗口即可停止本地服务器

如果没有 Python，也可以直接双击 `index.html` 打开。

## 发给同学试玩

把整个文件夹打包成 zip 发给对方即可，确保这些文件都在：

```text
index.html
start_game.bat
assets/
css/
js/
README.md
```

对方解压后双击 `start_game.bat` 就能玩。

## 操作

玩家一：

- 接宝石：`A`、`D`
- 节奏点击：`W`、`A`、`S`、`D`
- 三线跑酷：`A`、`D`
- 技能：`J`、`K`，PK 中可从 4 个技能里选择 2 个

玩家二：

- 接宝石：`←`、`→`
- 节奏点击：`↑`、`←`、`↓`、`→`
- 三线跑酷：`←`、`→`
- 技能：`1`、`2`，PK 中可从 4 个技能里选择 2 个

系统：

- `Esc` 或 `Tab`：暂停 / 控制面板

- 合作无限：无限波次、精英波、Boss 波
- PK 双线对抗：左右基地互攻，限时或基地归零结算

- 合作闯关流程：合作模式 -> 闯关模式 -> 关卡选择 -> 双人小游戏选择 -> 开始当前关
- 关卡进度会保存到浏览器 localStorage，默认只解锁第 1 关，通关后逐关解锁
- PK 设置页支持共同小游戏选择和双方 2 技能配置
- 主战场已改为约 40% 高度的左右双基地三路推进区，下方操作区约 60%
- 6 种召唤物、8 种敌人、4 个技能
- 本阶段使用 image gen 重新生成并接入了 8 张三路关卡地图、接宝石人物动作图和三线跑酷背向人物动作图
- 接宝石人物改为拿篮子的完整角色；节奏点击不再绘制人物，只保留四轨音游界面、音符和判定反馈
